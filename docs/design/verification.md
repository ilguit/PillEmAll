Тестовый эмулятор API 36 запускался отдельно от подключённого телефона, но без доступного аппаратного ускорения не завершил загрузку за время проверки. После появления сервиса package попытка установки APK была отклонена: `device is still booting`. Эмулятор остановлен. Скриншоты нового запущенного интерфейса и инструментальные тесты на устройстве не получены. На пользовательский телефон APK не устанавливался, данные не менялись.

Остаётся ручной осмотр обеих тем, крупного шрифта, трёх вкладок, форм и системных диалогов выбора даты/времени на устройстве. JVM-тест запуска Activity прошёл; он не заменяет визуальную проверку.
